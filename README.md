## About this repository

This public repository contains an earlier BookLog codebase and is retained as historical source. Its local build output is not evidence of the version currently published on Google Play.

The original app lets a user search the Google Books catalog and add personal information about a book. Books are stored in a local SQLite database and shown on a virtual bookshelf, which can be organized with sort and filter settings.
